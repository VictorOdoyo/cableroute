# neutral 02

Balanced fundamental 20 A cancels. Three in-phase third harmonics of 2 A sum to 6 A. A single fifth-order phase contributes 2 A. Different frequencies combine by root-sum-square.

Expected values are recorded in [the reference fixture](../../references/neutral_02.json). The executable regression uses relative tolerance 1e-8 and absolute tolerance 1e-8 unless a tighter residual is specified. Values are analytical examples, not standard ampacity or compliance limits.
