# neutral 03

Balanced fundamental 30 A cancels. Three in-phase third harmonics of 3 A sum to 9 A. A single fifth-order phase contributes 3 A. Different frequencies combine by root-sum-square.

Expected values are recorded in [the reference fixture](../../references/neutral_03.json). The executable regression uses relative tolerance 1e-8 and absolute tolerance 1e-8 unless a tighter residual is specified. Values are analytical examples, not standard ampacity or compliance limits.
