# parallel 05

Total current 150 A, path impedances in a 1:2 ratio with the same angle. Equal terminal voltage gives current division 2:1. Complex branch currents must sum to total injection.

Expected values are recorded in [the reference fixture](../../references/parallel_05.json). The executable regression uses relative tolerance 1e-8 and absolute tolerance 1e-8 unless a tighter residual is specified. Values are analytical examples, not standard ampacity or compliance limits.
