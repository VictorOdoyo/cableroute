# selection 01

Integrated feeder with 5 kW demand basis, 10 m route and 20 A protective rating. Reference independently combines load current, derated ampacity, 20 V drop limit and adiabatic minimum. Every candidate feasibility bit is checked.

Expected values are recorded in [the reference fixture](../../references/selection_01.json). The executable regression uses relative tolerance 1e-8 and absolute tolerance 1e-8 unless a tighter residual is specified. Values are analytical examples, not standard ampacity or compliance limits.
