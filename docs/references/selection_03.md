# selection 03

Integrated feeder with 15 kW demand basis, 30 m route and 60 A protective rating. Reference independently combines load current, derated ampacity, 20 V drop limit and adiabatic minimum. Every candidate feasibility bit is checked.

Expected values are recorded in [the reference fixture](../../references/selection_03.json). The executable regression uses relative tolerance 1e-8 and absolute tolerance 1e-8 unless a tighter residual is specified. Values are analytical examples, not standard ampacity or compliance limits.
