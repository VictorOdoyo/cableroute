# selection 04

Integrated feeder with 20 kW demand basis, 40 m route and 80 A protective rating. Reference independently combines load current, derated ampacity, 20 V drop limit and adiabatic minimum. Every candidate feasibility bit is checked.

Expected values are recorded in [the reference fixture](../../references/selection_04.json). The executable regression uses relative tolerance 1e-8 and absolute tolerance 1e-8 unless a tighter residual is specified. Values are analytical examples, not standard ampacity or compliance limits.
